Credentials configuration Meross Local Pairer app

Install Meross Local Pairer on your Android device. It is distributed on GitHub, not on the Play Store.

Download Meross Local Pairer

The legacy "Custom Pairer" application from the Play Store is not used by this add-on.

 Login with Meross Local Pairer
  • Open Meross Local Pairer and log in to the local broker API.
  • Make sure WiFi is enabled and connected to the same network where Homeassistant is running. Please note that you will also need to enable location (gps) for the discovery, as Android requires GPS permissions to scan nearest WIFIs.
  • Tap on Discovery. This will auto-populate the HTTP server hostname input field. If this doesn't work, then it is highly probable that either the App or Homeassistant are not on the same network. In such cases, you need to identify the network address of the HomeAssistant instance and fill this value as follows: 
      http://HA_IP:ADDON_API_PORT

  Where: 
    - HA_IP is the IP address of the HomeAssistant device. The default is homeassistant.local.
    - ADDON_API_PORT is the port, on the host of HA, where the Addon is listening. The default is 2003.
  • Enter the local login and password created in step 1.
  • Tap on "Login" and make sure the login succeeds.
 Pair Meross devices

You can now pair your Meross hardware devices with this local add-on.

In Meross Local Pairer, follow the pairing procedure described in its README.

Note: reset your Meross devices before pairing them with Meross Local Pairer.

Configure HomeAssistant

Install the Meross Cloud IoT integration from mazkagaz/meross-cloud, choose the LAN-only broker mode, and use the local login created in step 1.
