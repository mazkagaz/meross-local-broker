Broker access

Create the local login used by Meross Local Pairer and the Home Assistant integration. This account is independent from Meross: the add-on never contacts the Meross cloud.

Meross Local Pairer

Install the Android app that pairs your devices with this broker. It is distributed on GitHub, not on the Play Store.

Download Meross Local Pairer

The legacy "Custom Pairer" application from the Play Store is not used by this add-on.

 Pair devices
  1. Connect the phone to the same Wi-Fi network as Home Assistant and open the pairer.
  2. The broker address is discovered automatically. Enter the local login created in "Broker access".
  3. Reset the Meross device, then follow the guided pairing.
  4. Give the device a unique name. It is kept if the device is forgotten later.

The pairer offers to trust the current Wi-Fi network. Device access points are always allowed.

Home Assistant

Install the Meross Local Cloud integration with HACS, choose the LAN-only broker mode, and use the local login created in "Broker access".

The broker is advertised over mDNS, so the integration can find it automatically.
