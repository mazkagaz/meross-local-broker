Meross Local Broker Version {{ version }}

A local replacement for the Meross cloud: it runs the MQTT broker and the local API used by Meross devices, the Android pairer and the Home Assistant integration.

Principles
  • Local only: no Meross cloud account, no tracking, no telemetry, no ads.
  • Passwords and device data stay in your Home Assistant installation.
  • MQTT and the API can run over TLS, with certificate pinning in the pairer.
  • Free and open source. Provided as is, without warranty.
