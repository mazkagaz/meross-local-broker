# Support MRS100 (volet roulant)

Le **MRS100** est la cible principalement testée du broker local. Les modèles
voisins reconnus comme volets roulants (`mss560`, `mss570`, `mrs200`) utilisent
les mêmes chemins, mais sont testés par la communauté : signalez le modèle, le
firmware et les fonctions qui marchent ou non.

## Entités créées par l'intégration

Pour un volet roulant, Meross Local Cloud crée :

- une entité **cover** (ouvrir/fermer/stop, position) ;
- deux entités **number** : durée d'ouverture et durée de fermeture, bornées à
  **10–120 secondes** ;
- deux boutons de calibration : **Start calibration** et **Stop calibration** ;
- un capteur **Calibration status**.

Le capteur de calibration prend les valeurs `in_progress`, `success`,
`timeout`, `motor_blocked`, puis `failed_N` pour les codes constructeur non
documentés.

## Persistance des durées

Le device ne conserve pas toujours ses durées d'ouverture/fermeture. Le broker
les stocke (namespace `Appliance.RollerShutter.Config`) et les réapplique :

- à la réception d'un `System.All` après reconnexion ;
- au plus une fois toutes les **5 minutes** par appareil, pour éviter les
  boucles si le device refuse la configuration.

Les messages `Stored roller-shutter config` et `Re-applied roller-shutter config` du journal de l'add-on confirment le mécanisme.

Le broker cache aussi `RollerShutter.Position`, `RollerShutter.State` et les
résultats de calibration `RollerShutter.Adjust`. Une commande de calibration
est une action, jamais une configuration : elle n'est pas rejouée.

## Appairage

- **Firmware 7** : AP Wi-Fi `Meross_RS_*`, via
  [Meross Local Pairer](https://github.com/mazkagaz/meross-local-pairer).
- **Firmware 8 / Bluetooth LE** : publicité `MRBL_*`, appairage BLE dans le
  pairer (`Appliance.Config.WifiX`).

Le pairer et l'intégration utilisent **HTTPS 2004** ; le port 2003 est réservé
à l'ingress Home Assistant.

## Oubli et réappairage

**Forget device** révoque le MAC et publie `Appliance.Control.Unbind`. Un
nouvel appairage réussi restaure le même UUID : les entités et automatisations
Home Assistant restent valides.

## Limites connues

- Canal 0 principalement ; les devices multi-canaux ne sont pas couverts.
- Les autres modèles de volets sont reconnus mais moins testés.
- L'archive technique du patch initial est dans
  [MRS100_PATCH.md]../design/MRS100_PATCH.md ; la référence des tests est
  [TESTING.md]../testing/TESTING.md.
