Broker access

Create the local login used by Meross Local Pairer and the Home Assistant integration. This account is independent from Meross: the add-on never contacts the Meross cloud.

Home Assistant

Install the Meross Local Cloud integration with HACS and configure it with the local login created above. It only works with this local broker; no cloud mode is offered.

The broker is advertised over mDNS, so the integration can find it automatically.

 Pair devices

Install the Android app that pairs your devices with this broker. It is distributed on GitHub, not on the Play Store.

Download Meross Local Pairer Pairing procedure
  1. Connect the phone to the same Wi-Fi network as Home Assistant.
  2. Open the pairer. It discovers this broker and fills in its address automatically.
  3. Log in with the local account created in the Setup page.
  4. Reset the Meross device, then follow the guided pairing and give it a unique name.

The app offers to trust the current Wi-Fi network. Device access points are always allowed. If discovery fails, type the Home Assistant host or IP only (for example homeassistant.local); the API port is selected automatically.
