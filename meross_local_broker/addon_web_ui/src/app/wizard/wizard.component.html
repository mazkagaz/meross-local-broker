Create the local account Install Meross Local Pairer

Install Meross Local Pairer on your Android phone. It is distributed on GitHub, not on the Play Store.

Download Meross Local Pairer

The legacy "Custom Pairer" application from the Play Store is not used by this add-on.

 Connect the pairer
  • Connect the phone to the same Wi-Fi network as Home Assistant.
  • Open the pairer. It discovers this broker and fills in its address automatically.
  • Keep HTTPS enabled. Plain HTTP is reserved for the Supervisor ingress and is not reachable from the LAN.
  • Log in with the local account created in step 1.

If discovery fails, type the Home Assistant host or IP only (for example homeassistant.local). The app selects the API port automatically; advanced users can change the HTTP and HTTPS ports in its settings.

Pair Meross devices

Reset the Meross device, then follow the guided pairing in the app.

Give the device a unique name. The name and its Home Assistant entities are kept if the device is forgotten later.

The pairer offers to trust the Wi-Fi network used for your devices. Device access points are always allowed.

Configure Home Assistant

Install the Meross Local Cloud integration from mazkagaz/meross-local-cloud, and configure it with the local account created in step 1. It only works with this local broker; no cloud mode is offered.
